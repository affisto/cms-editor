# Blockroom 폼 제작 스튜디오

루트에서 `npm ci`, `npm run build:packages`, `npm run dev --workspace=docs`를 실행합니다.

- 주소: http://127.0.0.1:4310
- 작성·질문 설정·미리보기·응답 제출
- 현재 브라우저에 문서와 응답 저장, JSON 가져오기·내보내기
- 실제 서비스 API는 `src/studio/storage.ts`의 데모 어댑터 대신 연결

전체 기능, 검증 명령, 지원 범위는 [루트 README](../../README.md)와 [통합 가이드](../../docs/integration.md)를 참고하세요.
