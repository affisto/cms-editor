## 검증의 한계와 운영 연결

- 실제 저장/업로드/응답 서버는 이 저장소의 범위에 없습니다. 데모는 localStorage와 파일 읽기 어댑터를 사용합니다. 외부 서버 연결은 주입 인터페이스와 예제로 제공합니다.
- Chromium에서 자동 검증했습니다. Safari/Firefox, 실제 모바일 기기, OS 한글 IME 조합, 스크린 리더 조작은 별도 실기기 검증이 필요합니다. 한글 문자열 입력 테스트는 실제 IME 검증과 동일하지 않습니다.
- 다른 웹 프레임워크는 DOM API로 연결할 수 있습니다. Vue/Svelte/Angular 자체 런타임과 네이티브 WebView는 이번 검증에 포함하지 않았습니다.
- 500개 문단의 데이터/HTML 처리는 검사했으나 대형 문서의 실기기 입력 지연, 업로드 대역폭, 대량 동시 제출을 부하 시험하지는 않았습니다.
- 문서 버전은 현재 v1입니다. 미래 버전과 미등록 블록을 조용히 삭제하지 않고 오류 처리합니다. 과거 형식으로부터의 마이그레이션은 실제 다음 버전이 생길 때 추가해야 합니다.
- 테이블·영상·다단 레이아웃, 폼 첨부파일·조건부 질문·다단계 폼, 공동 편집과 완전한 다국어 UI는 후속 범위입니다.
- 저장소 전체의 기존 Gatsby/공통 개발 도구에는 의존성 감사 경고가 남아 있습니다. 새 코어 런타임 감사와 구분해야 합니다. 데모까지 공개 운영하려면 전체 의존성 업그레이드를 별도로 검토하세요. 강제 일괄 업그레이드는 적용하지 않았습니다.

기존 Browserslist 데이터의 갱신 권고, Gatsby 예제의 Tailwind utility 사용 없음, Next.js 전용 ESLint 플러그인 미설정 경고가 있습니다. 현재 공통 ESLint와 TypeScript 검사 및 프로덕션 빌드는 통과합니다.
